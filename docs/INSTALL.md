# 手机安装与验收指引（v0.1.0）

> 当前线上内容版本：**content v2（4 个关卡）**，APK 版本 0.1.0（debug 签名，测试分发）。
> 作者演示服（可能随时关闭）：`https://zzysjqr.cn/treasure/`
> 安装到自己的服务器请先按 [DEPLOY.md](DEPLOY.md) 部署，再修改 APK/前端里的 API 地址重新构建。

## 1. 下载与安装

**手机浏览器打开：**

```
https://zzysjqr.cn/treasure/apk/treasure-quest-0.1.0-debug.apk
```

或扫描二维码：

![APK 下载二维码](screenshots/apk-qr.png)

步骤：

1. 手机浏览器打开链接下载 APK（约 158KB）
2. 浏览器提示「此类型文件可能有害」→ 仍要下载
3. 点击安装；系统提示「禁止安装未知应用」→ 设置 → 允许该浏览器安装未知应用
4. 部分机型（小米/红米、OPPO、vivo、荣耀）需在「设置 → 安全 → 安装外部来源应用」单独授权
5. 桌面出现「寻宝奇兵」图标（金色宝石）

> debug 签名可能触发 Play 保护提示：点「更多详情 → 仍要安装」。

## 2. 首次打开

- 横屏全屏，登录页；测试账号 **admin / 123456** 或「游客试玩」（游客不需要网络）
- 首次启动从 APK 内置内容加载，断网也可玩
- 进度自动保存在本机（卸载会清空）

## 3. 验收清单

| # | 操作 | 预期 |
|---|---|---|
| 1 | 安装并打开 | 横屏全屏、登录页正常，不白屏/闪退 |
| 2 | admin/123456 登录 | 进入主菜单，显示「测试玩家」 |
| 3 | 开始游戏 → 第 1 关 | 摇杆移动、攻击按钮可用 |
| 4 | 收集 5 宝石 → 进传送门 | 结算、解锁第 2 关 |
| 5 | 杀 APP 重开 | 进度保留 |
| 6 | 设置 → 版本信息 | 显示内容版本（内置 v1） |
| 7 | 返回键 / 切后台 | 不闪退；后台暂停、回来不自动继续 |
| 8 | 设置 → 检查更新 | 线上有 v2 → 显示更新说明；下载 → 重启生效后为 v2（4 关） |

老存档说明：v1 中已通关第 3 关的玩家，更新到 v2 后会自动解锁第 4 关，无需重打。

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| 浏览器下载被拦截 | 允许安装未知应用；或换系统浏览器 |
| 安装解析失败 | 下载不完整，重新下载；确认 Android 8.0+ |
| 覆盖安装失败 | 旧签名不同：先卸载旧版 |
| 打开白屏/闪退 | 卸载重装；记录机型 + Android 版本反馈 |
| 登录网络错误 | 检查手机能否访问 `https://zzysjqr.cn/treasure/api/health`；可先用游客模式 |
| 检查更新无反应 | 线上 v2 已发布；确认网络与 APP 版本 |
