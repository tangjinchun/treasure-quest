# 测试计划与验收标准（v1）

## 1. 自动化测试（每次改动必跑）

| 测试 | 命令 | 通过标准 |
|---|---|---|
| 关卡/地图逻辑 | `node --test tests\game\` | 全绿：地图尺寸、P/E 唯一、宝石数量、BFS 可达性、锁门逻辑 |
| Web 静态校验 | `python tools\validate_web.py` | `VALIDATE_WEB_OK`：文件齐全、脚本顺序正确、JS 语法通过、无外链、< 400KB |
| 后端单测 | `python -m unittest discover -s server\tests -v` | 全绿：health/version/login/me/stats/静态/CORS/限流/路径穿越 |
| OTA 客户端模拟 | `python tools\ota_client_sim.py --api-base ... --current-version N` | `OTA_APPLIED`：sha256 一致、解压安全、bundle 校验通过 |
| APK 构建验证 | `python tools\build_apk.py` | `apksigner verify` 通过、包名/版本正确、`aapt2 dump badging` 正常 |

## 4. OTA 端到端验收（核心）

| # | 步骤 | 预期 |
|---|---|---|
| O1 | 发布 content v2（`build_web.py --version 2` + `publish_content.py`） | 公网 `/api/version` 显示 version=2、sha256 正确 |
| O2 | 手机 APP：设置 → 检查更新 | 弹出更新说明与大小 |
| O3 | 点下载 | 进度条正常；服务器 `stats.jsonl` 出现 download 记录 |
| O4 | 下载完成 → 重启生效 | 设置页显示内容版本 v2；新内容（如第 4 关）出现 |
| O5 | 断网检查更新 | 提示网络错误，当前版本可继续玩 |
| O6 | 服务器版本回退/损坏包（开发环境构造） | 校验失败提示，当前版本不受影响 |
| O7 | 覆盖安装新版 APK（同签名） | 保留数据与已下载内容，正常启动 |

## 5. 安全与稳定性检查

- [ ] APP 只请求 HTTPS，无明文流量配置
- [ ] 内容包下载校验 sha256；zip-slip 测试（在 zip 里放 `../evil` 应被拒绝）
- [ ] 登录接口限流生效（连续 11 次错误密码 → 429）
- [ ] token 过期/伪造 → 401
- [ ] `/api/stats` 无管理员 token → 403
- [ ] 服务重启后 APP 仍能正常登录/更新（无内存态依赖）
- [ ] 服务器上现有其它站点/服务未被影响

## 6. 已知限制（v1 明确不做）

- 单测试账号，无注册/找回密码；账号密码 `admin/123456` 仅测试用，后续必须替换。
- 无云存档；存档在手机本地，卸载/清数据会丢失。
- 无 APK 自动更新（内容 OTA 不包含壳代码更新；壳更新需重新下载 APK 覆盖安装）。
- 浏览器模式不能应用 OTA，仅演示接口。
- 未做多分辨率极端适配/iOS；横屏锁定。
